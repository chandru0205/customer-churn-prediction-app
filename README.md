# Customer Churn Prediction System

### Machine Learning–Powered Web Application for Telecom Customer Retention

**Live Demo:** https://customer-churn-prediction-app-pvgvrue8fipyztbszm3d8y.streamlit.app/

## 1. Project Overview

A machine learning web application that predicts customer churn in the telecommunications industry. It helps identify customers who may discontinue their services, enabling businesses to take proactive retention measures.

## 2. Problem Statement

Customer churn can lead to revenue loss and reduced customer retention. Identifying customers at risk of leaving allows telecom companies to develop targeted retention strategies and improve customer relationships.

## 3. Key Features

* Processed and prepared a dataset containing 7,043 telecom customer records.
* Trained and compared three machine learning models: Logistic Regression, Decision Tree, and Random Forest.
* Achieved approximately 79% classification accuracy on unseen test data.
* Developed an interactive web application using Streamlit.
* Generated churn probability predictions based on customer details.
* Provided suggested retention actions based on predicted churn risk.

## 4. Technology Stack

* **Programming Language:** Python
* **Data Processing:** Pandas
* **Machine Learning:** Scikit-learn
* **Web Application:** Streamlit

## 5. Key Findings

Customers with month-to-month contracts, shorter tenure, and no technical support tend to exhibit higher churn risk in the dataset.

These findings can help businesses identify customer segments that may benefit from targeted retention strategies.

## 6. Model Performance and Limitations

The selected model achieved approximately 79% accuracy on unseen test data. However, it identifies only around half of the customers who actually churn.

This indicates that accuracy alone does not fully reflect the model's effectiveness in identifying at-risk customers.

## 7. Future Enhancements

* Address class imbalance to improve churn detection.
* Explore additional customer features to improve predictive performance.
* Evaluate precision, recall, F1-score, and ROC-AUC.
* Enhance the application with customer risk categories and retention analytics.

## 8. Project Outcome

Developed and deployed an interactive machine learning application that estimates telecom customer churn probability and supports data-driven customer retention decisions.
